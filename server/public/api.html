Price API

Version 1 · free · no key needed

Auction House prices seen in game by TLI Companion players, for your site, bot or tool. Read only, open to every website (CORS), cached 10 minutes.

  • Our prices only: Auction House searches captured by TLI Companion players. Prices from other sources are not included.
  • At least 3 players: an item is listed only if at least 3 players saw its price in the last 7 days. A history day is listed only if 3 players saw it that day.
  • Prices in FE (Flame Elementium). Item ids are the game's ids.
  • Version 1 stays stable: fields can be added, never removed or renamed.

One item, with its history

GET https://tlicompanion.com/api/public/v1/prices/100200?days=30

Same fields as above, plus days (1 to 120, 30 by default) and history: one entry per day (UTC).

"history": [
  { "day": "2026-10-26", "median": 0.0121, "low": 0.0110, "high": 0.0140, "players": 21 },
  { "day": "2026-10-27", "median": 0.0125, "low": 0.0118, "high": 0.0131, "players": 17 }
]

Fields

FieldMeaning
priceCurrent price: median of the latest price each player saw in the last 7 days.
players7dNumber of players who saw a price for this item in the last 7 days.
updatedAtWhen the latest price for this item was seen.
change24h, change7dChange compared with the daily median 1 day and 7 days ago. 0.05 = +5 %. null when unknown.
categorySame categories as the Prices page, other when unknown.
iconItem icon URL, or null.

Limits

  • 60 requests per minute per address. Above that, the answer is 429.
  • Data changes at most every 10 minutes: no need to ask more often. Fetch the full list once and keep it.
  • Errors come as { "error": "…" } with a 4xx code. An unknown item, or one seen by fewer than 3 players, gives 404.

Example

const r = await fetch('https://tlicompanion.com/api/public/v1/prices');
const { items } = await r.json();
const byId = Object.fromEntries(items.map((i) => [i.id, i]));
console.log(byId[100200]?.price);

API des prix

Version 1 · gratuite · sans clé

Les prix de l'hôtel des ventes vus en jeu par les joueurs de TLI Companion, pour ton site, ton bot ou ton outil. Lecture seule, ouverte à tous les sites (CORS), mise à jour toutes les 10 minutes.

  • Nos prix seulement : les recherches à l'hôtel des ventes captées par les joueurs de TLI Companion. Les prix d'autres sources ne sont pas inclus.
  • Au moins 3 joueurs : un objet n'apparaît que si au moins 3 joueurs ont vu son prix ces 7 derniers jours. Un jour de l'historique n'apparaît que si 3 joueurs l'ont vu ce jour-là.
  • Prix en FE (Flame Elementium). Les identifiants des objets sont ceux du jeu.
  • La version 1 reste stable : des champs peuvent être ajoutés, jamais retirés ni renommés.

Merci de nous citer

Affiche « Prices: tlicompanion.com » (ou « Prix : tlicompanion.com ») avec un lien vers https://tlicompanion.com là où tu montres ces prix.

Tous les objets

GET https://tlicompanion.com/api/public/v1/prices

Renvoie items : pour chaque objet id, name (en anglais), icon, category, price, players7d, updatedAt, change24h, change7d. Le détail des champs est dans la version anglaise de cette page.

Un objet, avec son historique

GET https://tlicompanion.com/api/public/v1/prices/100200?days=30

Les mêmes champs, plus days (1 à 120, 30 par défaut) et history : un point par jour (UTC) avec median, low, high et players.

Limites

  • 60 requêtes par minute et par adresse. Au-delà, la réponse est 429.
  • Les données changent au plus toutes les 10 minutes : inutile de demander plus souvent.
  • Les erreurs arrivent sous la forme { "error": "…" } avec un code 4xx. Un objet inconnu, ou vu par moins de 3 joueurs, donne 404.
